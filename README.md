E-Wallet System

Overview

This is a console-based E-Wallet system developed in C++ as part of an Object-Oriented Programming (OOP) project in the 2nd semester. The system allows users to manage their digital wallet, perform transactions, check balance, and track transaction history.

Features

User registration and login system

Secure PIN-based authentication

Deposit and withdraw funds

Transfer money between users

View transaction history

Simple and interactive console interface

Technologies Used

C++ (Object-Oriented Programming concepts)

File handling for data storage
